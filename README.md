# GHBasic Pro Portfolio

GHBasic Pro is a cloud-based school management and automated report card platform developed for Ghanaian basic schools.

## Features

* Student management
* Teacher management
* Automated report card generation
* Academic performance analytics
* BECE aggregate calculation
* Excel import and export
* Role-based access control
* Multi-user administration
* Offline data collection workflows

## Technologies Used

* PHP
* MySQL
* JavaScript
* AJAX
* HTML/CSS
* Chart.js

## My Role

I designed and developed the platform independently, including:

* Database architecture
* Backend development
* Frontend interfaces
* Authentication and authorization
* Report generation
* Data analytics
* Deployment and maintenance
